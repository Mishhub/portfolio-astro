This is an internal assistant built for customer support at LMNTO. It answers the
questions that used to escalate to product or engineering: how a feature is
implemented, what its PRD specifies, and why an issue is happening for a
specific user.

Under the hood it's a **LangGraph** graph served by **FastAPI**: query
understanding and a **planner/router** hand each question to specialist agents —
**pgvector** RAG over implementation docs and PRDs, a **SQL-agent subgraph** over
a SQLAlchemy data-access layer, and knowledge-base tools — and a response
synthesizer composes the final answer. Agents run with read-only, scoped tool
permissions, PII redaction and prompt-injection guardrails, and every run is
traced in **LangSmith**.

The linked case study walks through the graph, the specialist agents, the
fallback routing and the guardrails that make it safe to put in front of support.
